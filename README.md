# Twitter/X Homepage Clone

A responsive Twitter/X-inspired homepage developed as part of the **Zaio Full Stack Development Bootcamp**.

## Project Overview

This project recreates the core interface and interactive features of a Twitter/X social media feed using HTML, CSS, and JavaScript.

The objective is to demonstrate frontend development skills, responsive web design, JavaScript functionality, and the integration of independently developed and AI-assisted features.

## Features

- Responsive desktop and mobile layouts
- Home timeline with For You and Following tabs
- Create posts with a 280-character limit
- Like, Reply, and Share interactions
- Follow and Unfollow functionality
- Dark and Light Mode toggle
- Interactive Compose Post modal
- Explore page with tweet search functionality
- Floating Post button for mobile devices
- Synchronised post interactions between Home and Explore

## Custom Features

### Independent Feature — Dark/Light Mode Toggle

A theme-switching feature that allows users to alternate between dark and light appearances.

### Cursor-Assisted Feature 1 — Compose Post Modal

An interactive modal that allows users to create and publish posts, with character-count validation and responsive styling.

### Cursor-Assisted Feature 2 — Explore Page and Search

An Explore interface that allows users to search and discover posts using keyword-based filtering.

## Running the Project

1. Download or clone this GitHub repository.
2. Open the `Twitter X Home PageFeed` folder in Visual Studio Code.
3. Open `index.html` using Live Server or a web browser.
4. Explore the homepage and test its interactive features.

## Project Limitations

This project is a frontend prototype and does not currently include backend authentication or database storage.

Posts, likes, replies, and other interactions are stored temporarily in the browser's page session and may reset when the page is refreshed.
